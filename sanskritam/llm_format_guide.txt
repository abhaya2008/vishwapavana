MANIMANJARI COMMENTARY — LLM FORMAT GUIDE
==========================================
Use this guide to generate commentary for Manimanjari shlokas.
Paste the output directly into the "📋 Bulk Import" dialog in the Sanskritam app.

═══════════════════════════════════════════════════════════
PDF SOURCE — SCRIPT SITUATION (READ THIS FIRST)
═══════════════════════════════════════════════════════════
The uploaded Manimanjari PDF is a South Indian publication where:

  ✦ Sanskrit content is written in KANNADA SCRIPT
    (e.g., "ವಂದೇ ಗೋವಿಂದಮಾನಂದ" = Sanskrit "वन्दे गोविन्दमानन्द")
    This includes: the shloka, avatarnika, padaccheda, anvaya, samasa, sandhi,
    dhatu forms, tatparya, vishesha, akanksha, Sanskrit vyakhyana,
    gudaprakashika commentary, and all grammar analysis.

  ✦ Actual Kannada language text (meanings, explanations for students)
    is also in Kannada script — this is GENUINE Kannada, not Sanskrit.
    (e.g., "ನಾನು ಭಗವಂತನನ್ನು ನಮಸ್ಕರಿಸುತ್ತೇನೆ" = real Kannada sentence)

THE CORE RULE:
  ► Identify whether each piece of text is Sanskrit-language or Kannada-language
  ► Sanskrit language content (regardless of script in source) → output in DEVANAGARI
  ► Genuine Kannada language content → keep in KANNADA script

How to tell them apart:
  Sanskrit in Kannada script has Sanskrit grammar — case endings (ಂ, ಃ, ಾ),
  Sanskrit sandhi patterns, verb conjugations, compound words (ಸಮಾಸ).
  Genuine Kannada has Kannada grammar — ಯ, ಳ, ತ್ತೇನೆ, ಮಾಡಿದ, ಆಗಿದ್ದಾರೆ.

PER-SECTION SCRIPT RULES:
  ## AVATARNIKA         → Devanagari (Sanskrit content) — introduction, shown before the shloka
  ## PADACCHEDA         → Devanagari (Sanskrit content)
  ## ANVAYA             → Devanagari (Sanskrit content)
  ## ANVAYARTHA         → col 1: Devanagari word | col 2: Kannada meaning | col 3: Sanskrit meaning ← TABLE
  ## SHABDA             → ALL Devanagari (Sanskrit grammar analysis) ← TABLE (6 columns)
  ## SAMASA             → Devanagari (Sanskrit content)
  ## SANDHI             → Devanagari (Sanskrit content)
  ## DHATU              → Devanagari (Sanskrit content)
  ## TATPARYA           → Devanagari (Sanskrit content)
  ## TATPARYA_KANNADA   → Kannada (Kannada-language meaning, shown after TATPARYA)
  ## VISHESHA           → Devanagari (Sanskrit content)
  ## AKANKSHA           → Devanagari (Sanskrit content)
  ## SANSKRIT_VYAKHYANA → Devanagari (Sanskrit content) — displayed as "मणिमञ्जरी-प्रकाशः"
                          SOURCE-ONLY — do not generate; omit if absent from source
  ## GUDAPRAKASHIKA     → Sanskrit parts → Devanagari
                          Kannada explanatory sentences → Kannada
                          SOURCE-ONLY — do not generate; omit if absent from source

═══════════════════════════════════════════════════════════
SOURCE-ONLY SECTIONS — DO NOT FABRICATE
═══════════════════════════════════════════════════════════
## SANSKRIT_VYAKHYANA (मणिमञ्जरी-प्रकाशः) and ## GUDAPRAKASHIKA (श्रीमच्छलारि
गूडप्रकाशिका) are NAMED, SPECIFIC historical commentaries by named traditional
commentators — not generic explanations. Unlike other sections, these must be
extracted from the attached image/PDF ONLY.

  ► If the source contains this commentary for the shloka — extract it faithfully
    (converting Sanskrit-in-Kannada-script to Devanagari per the script rule).
  ► If the source does NOT contain it for this shloka — OMIT the section entirely.
    Do NOT generate, compose, or paraphrase content from your own Sanskrit knowledge
    and present it under these names. Inventing text and attributing it to a named
    historical commentary is a factual misattribution, not a helpful guess.
  ► This is the opposite of ## SANDHI, which must ALWAYS be generated even when
    absent from source (see TABLE FORMATS above) — SANDHI is generic grammatical
    analysis, not a named commentary, so there's nothing to misattribute.
  ► Every other section (AVATARNIKA, PADACCHEDA, ANVAYA, ANVAYARTHA, SHABDA, SAMASA,
    DHATU, TATPARYA, TATPARYA_KANNADA, VISHESHA, AKANKSHA) — extract from source if
    available, otherwise it's fine to compose/generate from your own Sanskrit
    knowledge, since these aren't attributed to a specific named commentator.

═══════════════════════════════════════════════════════════
SECTION HEADERS
═══════════════════════════════════════════════════════════
Each section starts with ## SECTION_NAME on its own line (uppercase, no extra text).
Content follows on the next lines until the next ## header.
Sections can appear in any order. Empty sections are silently ignored.

Valid section names:
  ## AVATARNIKA          → अवतरणिका        (introduction, shown before the shloka)
  ## PADACCHEDA          → पदच्छेदः       (word split)
  ## ANVAYA              → अन्वयः          (prose word order)
  ## ANVAYARTHA          → अन्वयार्थः      (word meanings: Kannada + Sanskrit)
  ## SHABDA              → शब्दः           (word meanings table)
  ## SAMASA              → समासः           (compound analysis)
  ## SANDHI              → सन्धिः          (sandhi analysis)
  ## DHATU               → धातुः           (verb conjugation table)
  ## TATPARYA            → तात्पर्यम्      (purport, Sanskrit)
  ## TATPARYA_KANNADA    → ತಾತ್ಪರ್ಯ         (purport, Kannada — shown right after TATPARYA)
  ## VISHESHA            → विशेषांशः       (special notes)
  ## AKANKSHA            → आकांक्षा        (syntactic expectation)
  ## SANSKRIT_VYAKHYANA  → मणिमञ्जरी-प्रकाशः                    (source-only, see below)
  ## GUDAPRAKASHIKA      → श्रीमच्छलारि गूडप्रकाशिका             (source-only, see below)

═══════════════════════════════════════════════════════════
TABLE FORMATS
═══════════════════════════════════════════════════════════

─── ## ANVAYARTHA (word | Kannada meaning | Sanskrit meaning table) ─
Three-column pipe-separated table (the app also accepts 2 columns and pads a blank
3rd column, but ALWAYS generate all 3 — the app's own अन्वयार्थः pane displays all
three: पदम् | अर्थः (कन्नड) | अर्थः (संस्कृत)).
Column 1: Sanskrit word/phrase from the shloka — DEVANAGARI
Column 2: Kannada meaning — KANNADA script (word meaning for Kannada-medium students)
Column 3: Sanskrit meaning — DEVANAGARI (a Sanskrit gloss/synonym/paraphrase of the
          same word — e.g. an equivalent word, short samasa-vigraha, or synonym —
          NOT a repeat of the word itself)
One entry per significant word, in the order they appear in अन्वयः.

NOTE: The app parser accepts BOTH plain format and Markdown table format:
  Plain (preferred):   अहम् | ನಾನು (ಗ್ರಂಥಕರ್ತ...) | ग्रन्थकर्ता श्रीमन्नारायणपण्डिताचार्यः
  Markdown (Gemini):   | अहम् | ನಾನು (ಗ್ರಂಥಕರ್ತ...) | ग्रन्थकर्ता ... |
Markdown separator rows (| --- | --- | --- |) are automatically skipped.
The header row (| पदम् | अर्थः (कन्नड) | अर्थः (संस्कृत) |) is also skipped if present.

Example:
## ANVAYARTHA
अहं | ನಾನು (ಗ್ರಂಥಕರ್ತೃಗಳಾದ ಶ್ರೀನಾರಾಯಣ ಪಂಡಿತಾಚಾರ್ಯರು) | ग्रन्थकर्ता श्रीमन्नारायणपण्डिताचार्यः
आनन्दज्ञानदेहं | ಆನಂದ ಮತ್ತು ಜ್ಞಾನಗಳನ್ನೇ ಶರೀರವಾಗಿ ಉಳ್ಳ | सुखं च ज्ञानं च त एव देहः (स्वरूपं) यस्य तं (सच्चिदानन्दविग्रहम्)
श्रियः | ಲಕ್ಷ್ಮೀ ದೇವಿಯರ | महालक्ष्म्याः
पतिं | ಪಾಲಕನಾದ | पालकम्
श्रीमदानन्दतीर्थार्यवल्लभं | ಶ್ರೀ ಮಧ್ವಾಚಾರ್ಯ ಭಗವತ್ಪಾದರ ಪ್ರಿಯನಾದ | श्रीमध्वाचार्यप्रियम्
परं | ದೇಶ-ಕಾಲ-ಗುಣಗಳಿಂದ ಪರಿಪೂರ್ಣನಾದ | देशकालगुणैः परिपूर्णम्
अक्षरं | (ಚತುರ್ವಿಧ) ನಾಶರಹಿತನಾದ | नाशरहितम्
गोविन्दं | ವೇದಾದಿ ವಾಗ್ರಾಶಿಗಳಿಂದ ತಿಳಿಯಲ್ಪಡುವ ನಾರಾಯಣನನ್ನು | वेदवाक्यैः ज्ञायमानं नारायणम्
वन्दे | ನಮಸ್ಕರಿಸಿ ಕೊಂಡಾಡುತ್ತೇನೆ | नमस्करोमि

─── ## SHABDA (Sanskrit grammatical analysis table) ──────
Six-column pipe-separated table. ALL columns in DEVANAGARI (Sanskrit only).
Exactly 6 columns per row — use — for fields that don't apply.

Column order:  पदम् | अन्तः | लिङ्गम् | शब्दः | विभक्तिः | वचनम्

  पदम्      — the word as it appears in the shloka
  अन्तः     — stem ending type (अकारान्त, इकारान्त, ईकारान्त, उकारान्त, etc.)
  लिङ्गम्   — gender (पुँल्लिङ्ग / स्त्रीलिङ्ग / नपुंसकलिङ्ग / — for sarvanama)
  शब्दः     — dictionary base form (प्रातिपदिकम्)
  विभक्तिः  — case (प्रथमा, द्वितीया, तृतीया … सप्तमी, सम्बोधन)
  वचनम्     — number (एकवचन / द्विवचन / बहुवचन)

Example:
## SHABDA
अहं | — | — | अस्मद् | प्रथमा | एकवचन
आनन्दज्ञानदेहं | अकारान्त | पुँल्लिङ्ग | आनन्दज्ञानदेह | द्वितीया | एकवचन
श्रियः | ईकारान्त | स्त्रीलिङ्ग | श्री | षष्ठी | एकवचन
पतिं | इकारान्त | पुँल्लिङ्ग | पति | द्वितीया | एकवचन
श्रीमदानन्दतीर्थार्यवल्लभं | अकारान्त | पुँल्लिङ्ग | श्रीमदानन्दतीर्थार्यवल्लभ | द्वितीया | एकवचन
परं | अकारान्त | पुँल्लिङ्ग | पर | द्वितीया | एकवचन
अक्षरं | अकारान्त | पुँल्लिङ्ग | अक्षर | द्वितीया | एकवचन
गोविन्दं | अकारान्त | पुँल्लिङ्ग | गोविन्द | द्वितीया | एकवचन

─── ## DHATU (verb conjugation) ─────────────────────────
Special keywords (exact spelling required):
  HEADER:  verb root + meaning, then in the bracket: gana + pada + the specific
           lakara/purusha/vachana of the FORM ACTUALLY USED IN THE SHLOKA — i.e.
           which lakara (लट्/लिट्/... — pick the same one marked "*" in LAKARA:),
           which पुरुष (उत्तमपुरुषः/मध्यमपुरुषः/प्रथमपुरुषः), and which वचन
           (एकवचनम्/द्विवचनम्/बहुवचनम्). One line, Devanagari.
           Format: HEADER: <root> <meaning> (<pada>, <gana>, <lakara>, <purusha>, <vachana>)
           e.g.: HEADER: वदिँ अभिवादनस्तुत्योः (आत्मनेपदी, भ्वादिगणः, लट्लकारे, उत्तमपुरुषे, एकवचने)
  NOTE:    optional रूपसिद्धि line (Devanagari) — a short derivation note explaining
           the specific verb form used in the shloka. Shown above the featured lakara
           in the app; omit this line entirely if there's nothing to add.
  LAKARA:  lakara name in Devanagari — starts each new conjugation block.
           Append a trailing " *" to mark ONE lakara as the "featured" one shown by
           default (e.g. "LAKARA: लङ् लकारः *") — pick whichever lakara matches the
           verb form actually used in the shloka. All 10 lakaras are still included
           and remain viewable via the app's "View all" popup; only ONE per HEADER
           block should carry the "*" marker. If omitted, the app defaults to the
           first lakara listed.

DATA SOURCE — look up exact verb forms here:
  https://github.com/ashtadhyayi-com/data/tree/master/dhatu

  Key files:
    data.txt                              — find the dhatu's "baseindex" (e.g. "01.0001")
    dhatuforms_vidyut_shuddha_kartari.txt — parasmaipada (p-keys: plat, plit, ...)
    dhatuforms_vidyut_shuddha_karmani.txt — atmanepada  (a-keys: alat, alit, ...)

  Each lakara value is 9 semicolon-separated forms in this fixed order:
    3sg ; 3du ; 3pl ; 2sg ; 2du ; 2pl ; 1sg ; 1du ; 1pl
    = प्र०एक ; प्र०द्वि ; प्र०बहु ; म०एक ; म०द्वि ; म०बहु ; उ०एक ; उ०द्वि ; उ०बहु
  Multiple alternative forms within one slot are comma-joined in the source —
  use the first (primary) form in the output.

PADA HANDLING:
  परस्मैपद  (pada=P): use p-keys only (plat, plit, plut, plrut, plot, plang, pvidhiling, pashirling, plung, plrung)
  आत्मनेपद  (pada=A): use a-keys only (alat, alit, alut, alrut, alot, alang, avidhiling, aashirling, alung, alrung)
  उभयपद     (pada=U): include both — label LAKARA blocks with "— परस्मैपद" / "— आत्मनेपद"
    Example for ubhayapada:
      LAKARA: लट् लकारः — परस्मैपद (वर्तमानकालः)
      LAKARA: लट् लकारः — आत्मनेपद (वर्तमानकालः)

Each conjugation row — 4 pipe-separated columns, all Devanagari:
  singular form | dual form | plural form | person label
Person labels: प्र० (3rd person), म० (2nd person), उ० (1st person)

─── ## SANDHI (sandhi analysis with grammatical basis) ───
Three-column pipe-separated table. All Sanskrit in DEVANAGARI.
Column order: सन्धिपदम् | शब्दौ | सन्धिप्रकारः

  सन्धिपदम्  — the joined word/phrase as it appears in the shloka
  शब्दौ      — the two original words/sounds before joining (X + Y)
  सन्धिप्रकारः — NOT just the type name. Must include THREE things in one cell:
                 (1) the sandhi type name (e.g. गुणसन्धिः)
                 (2) the governing Paninian sutra, if known (e.g. "आद्गुणः")
                 (3) a plain explanation of the phonetic change, i.e. which sound
                     became which and why (e.g. "अ + इ स्थाने ए")
               Format: <type name> — <sutra> — <phonetic change>
               Example: गुणसन्धिः — "आद्गुणः" (६.१.८७) — अ + इ स्थाने ए आदेशः

IMPORTANT — the source PDF almost never has a dedicated sandhi-analysis section.
Do NOT skip ## SANDHI just because it's absent from the source. Generate it
comprehensively from your own Sanskrit grammar (Paninian sandhi rules), covering
EVERY sandhi junction in the shloka's compound/joined words — one row per junction.

SANDHI TYPES — GRAMMATICAL BASIS (for reference; cite whichever applies per junction):

  स्वरसन्धिः (vowel sandhi):
    दीर्घसन्धिः  — "अकः सवर्णे दीर्घः" (६.१.१०१) — समान/सवर्ण स्वरयोः मेलने दीर्घः।
                    उदा: राम+अरिः → रामारिः (अ+अ→आ)
    गुणसन्धिः    — "आद्गुणः" (६.१.८७) — अकारात् परे इ/उ/ऋ/लृ सति गुणादेशः (ए/ओ/अर्/अल्)।
                    उदा: सुर+इन्द्रः → सुरेन्द्रः (अ+इ→ए)
    वृद्धिसन्धिः  — "वृद्धिरेचि" (६.१.८८) — अकारात् परे ए/ऐ/ओ/औ सति वृद्धिः (ऐ/औ)।
                    उदा: एक+एकः → एकैकः (अ+ए→ऐ)
    यण्सन्धिः    — "इको यणचि" (६.१.७७) — इ/उ/ऋ/लृ वर्णात् परे भिन्नस्वरे यण् (य्/व्/र्/ल्)।
                    उदा: इति+अपि → इत्यपि (इ+अ→य्)
    अयादिसन्धिः  — "एचोऽयवायावः" (६.१.७८) — ए/ऐ/ओ/औ वर्णात् परे स्वरे अय्/आय्/अव्/आव्।
                    उदा: ने+अनम् → नयनम् (ए+अ→अय्)

  व्यञ्जनसन्धिः (consonant sandhi):
    जश्त्वसन्धिः  — "झलां जशोऽन्ते" (८.२.३९) — पदान्त झल् वर्णस्य घोषवति परे जश् आदेशः।
                    उदा: वाक्+ईशः → वागीशः (क्→ग्)
    श्चुत्वसन्धिः — "स्तोः श्चुना श्चुः" (८.४.४०) — स/त वर्गस्य श/च वर्गसंयोगे श्चुत्वम्।
                    उदा: सत्+चित् → सच्चित् (त्→च्)
    अनुस्वारसन्धिः — "मोऽनुस्वारः" (८.३.२३) — पदान्त म्-कारस्य व्यञ्जने परे अनुस्वारः।
                    उदा: रामम्+वदति → रामं वदति (म्→ं)
